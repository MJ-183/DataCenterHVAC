## 규모 점검 (서울 샘플 대비 20배)

| 항목 | 결과 |
|---|---|
| 설비 대수 (설계일 최대 부하) | 칠러 8+1 (1대 3,517 kW, 최대 27,064 kW) · 냉각탑 10+1 (1대 4,100 kW, 최대 40,798 kW) · CDU 14+1 (1대 2,000 kW, 최대 26,780 kW) |
| CRAH | 남·북 각 28대 = 56대, 1대 14.8 m3/s (공기측 설계 풍량 ÷ 1대 상한 15 m3/s) |
| 배관 | 냉수 DN150~1000, 냉각수 DN1200 (관경 표 상한 DN1500 안), 냉수 양정 162 kPa, 최원단 349 m |
| 랙 흡입온도 | 최대 18.5℃ (상한 27℃), 초과 0개 — 규모 때문에 생긴 경고 없음 |

고친 고정값·범위 제한 (서울 샘플 결과 불변, 테스트로 확인):
- `CrahConfig.per_side` 상한 30 → 120 (`CRAH_PER_SIDE_MAX`), 연간 최적화·하루 최적화 탐색 범위·스케줄 적용 API 도 같은 상수 사용
- `plant_units.size_units` 연결: `cooling_layout.plant` 에 `chiller_unit_kw / tower_unit_kw / cdu_unit_kw / standby_units` 추가 (없으면 기존처럼 단일 설비), 냉각 구조 평가 결과 `units` 로 반환·화면 표시
- 배관 관경 표는 이미 DN1500 까지 있어 수정 없음

남은 관찰(고치지 않음):
- 냉수 배관 설계 유량은 엔진 총 냉방부하(액체 루프 포함) 기준이라 hybrid_dlc 에서 냉수관이 크게 잡힌다 (기존 연성 모델 규칙, 서울 샘플은 공랭이라 영향 없음)
- 3D 의 칠러·냉각탑은 대수와 무관하게 상자 하나로 그린다. 랙 격자는 고정 피치라 400랙이 130 x 65 m 홀 가운데 약 24 x 36 m 에 모여 있다
- 기류 모델은 단일 층이라 2개 층의 랙 400개를 한 층 평면에 배치한 것으로 근사
